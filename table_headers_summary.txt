Table Headers Analysis

Table 1:
Ticket ID หัวข้อปัญหา / รายละเอียด หมวดหมู่ ผู้แจ้ง / แผนก ความสำคัญ สถานะ & SLA ผู้รับผิดชอบ คะแนน CSAT จัดการ
-------------------
Table 2:
รหัสโครงการ ชื่อโครงการ / หมวดหมู่ Project Owner งบประมาณ (บาท) ความคืบหน้า (%) ระยะเวลา (เริ่ม - สิ้นสุด) Priority สถานะ จัดการ
-------------------
Table 3:
ผู้รับผิดชอบ (Assignee) แผนก / ฝ่าย รอดำเนินการ กำลังทำ รอตรวจสอบ เสร็จสิ้น รวมทั้งหมด อัตราความสำเร็จ (%)
-------------------
Table 4:
รหัสงาน ชื่องาน / รายละเอียด ผู้รับผิดชอบ วันที่เริ่ม กำหนดส่ง (Deadline) สถานะ จัดการ
-------------------
Table 5:
Asset Tag ชื่ออุปกรณ์ / รายละเอียด หมวดหมู่ Serial Number ผู้ถือครอง / แผนก สถานที่ตั้ง สถานะ ดำเนินการ
-------------------
Table 6:
ID รายการ ชื่อ Software / Vendor License Key / Account ประเภท โควต้าใช้งาน (Seats) วันหมดอายุ จัดการ
-------------------
Table 7:
Trans ID Asset Tag / อุปกรณ์ ผู้ยืม / แผนก วันที่ยืม กำหนดคืน สถานะ ดำเนินการ
-------------------
Table 8:
PM ID Asset Tag รายการที่ต้องตรวจเช็ค กำหนดทำ PM ผู้รับผิดชอบ สถานะ ดำเนินการ
-------------------
Table 9:
ID กล้อง ชื่อกล้อง / ตำแหน่ง พื้นที่ สถานะการทำงาน หมายเหตุ / อาการเสีย ดำเนินการ / ตรวจล่าสุด
-------------------
Table 10:
Job ID ชื่อ Server / ระบบ Target Backup Location สถานะสำรอง ขนาดไฟล์ (GB) หมายเหตุ ดำเนินการ / สำรองล่าสุด
-------------------
Table 11:
User ID ชื่อ - นามสกุล แผนก Role สิทธิ์ สถานะ ดำเนินการ
-------------------
Table 12:
วันที่กิจกรรม ประเภทกิจกรรม รายละเอียดกิจกรรม ผู้เกี่ยวข้อง / ผู้รับผิดชอบ สถานะรายการ
-------------------
